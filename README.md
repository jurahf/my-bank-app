
# my-bank-app

Заключительное задание для Яндекс.Практикум
Микросервисное приложение-банк.

## Компоненты
1. front - простой web ui для демонстрации работы. Вызывает сервисы через gatewayapi, отображает результаты, авторизация по логину и паролю через keycloak.
2. gatewayapi - точка входа для работы с API. Использует Consul для обнаружения сервисов, пересылает токен авторизации.
3. accounts - сервис аккаунтов. Авторизация по токену, обращается в notifications, использует Consul.
4. cash - сервис снятия и внесения наличных на счет. Авторизация по токену, обращается в accounts, использует Consul.
5. transfer - сервис перевода средств между счетами. Авторизация по токену, обращается в accounts, использует Consul.
6. notifications - сервис уведомлений. Авторизация по сервисному токену.
  

# Запуск в Docker
Соберите проект с помощью maven (должен появиться файл .jar в каталоге target):
`mvn clean package`  

Необходимо окружение, все запускается через docker-compose
1. Postgres - база данных. При первом запуске создаются схемы keycloak и accounts. Создается 2 тестовых пользователя. Для очистки/пересоздания данных нужно удалить volume.
2. Keycloack - сервис авторизации. Использует postgres в качестве хранилища. Для начала работы с сервисами необходимо создать пользователей user1 и user2 (которые соответствуют автоматически создаваемым в accounts в БД). Также необходимо создать клиенты bank-ui для аутентификации front через пользовательскую форму и account-service для сервисной авторизации.
3. Consul - используется в качестве Service Discovery.

`docker-compose up --build -d`
